# Focus Timer

집중 타이머 웹앱 (PC 웹 기준). HTML + CSS + JavaScript로 만들었고, 서버 프로그램 없이 브라우저에서 바로 동작합니다.

저장소: https://github.com/oojo-9/focus-timer

## 폴더 구조
```
focus-timer/
├─ index.html          화면 구조 (설정 / 진행 / 결과 3개 화면)
├─ css/
│  └─ style.css        디자인
├─ js/                 index.html에 적힌 순서대로 불러옴
│  ├─ utils.js         날짜·시간 포맷, 색 변환 등 공용 함수
│  ├─ config.js        테마·글꼴·기본 설정, 설정 저장
│  ├─ clock.js         시계 그리기 (화면 표시와 캡처가 같은 함수를 씀)
│  ├─ setup.js         설정 화면 (미리보기, 입력 바인딩)
│  ├─ camera.js        카메라와 얼굴 분석 모델
│  ├─ lecture.js       강의 모드 (유튜브 / 내 PC 영상 파일)
│  ├─ session.js       세션 시작·진행·잠금·이탈 감지·포기
│  ├─ timelapse.js     타임랩스 촬영과 영상 만들기
│  ├─ focus.js         집중도 분석
│  ├─ report.js        종료 처리, 완료 캡처, 결과 리포트
│  ├─ history.js       세션 기록과 추천 세션 길이
│  └─ main.js          공통 단축키·커서, 초기화 (마지막에 로드)
├─ changelog/
│  └─ changelog.md     수정내역
├─ .gitignore          GitHub에 안 올릴 파일 목록
└─ README.md
```
- 고치고 싶은 기능이 있으면 위 표에서 해당 파일만 열면 됩니다. 예: 시계 모양 → `clock.js`, 리포트 문구 → `report.js`
- 파일을 새로 추가하면 `index.html` 아래쪽 `<script>` 목록에도 넣어야 합니다. 순서가 중요해요 (`main.js`는 항상 마지막).

## 주요 기능
- 목표 시간 스탑워치 / 카운트다운, 3초 길게 눌러야 포기
- 집중 모드: 전체화면 + Esc 길게 눌러야 해제(Chrome/Edge), 뒤로가기·닫기 방지, 화면 꺼짐 방지
- 이탈 기록: 다른 창/탭으로 이동, 알림 클릭, 전체화면 해제
- 완료 시 화면 자동 캡처 (완료 날짜·시각 포함 PNG)
- 시계 꾸미기: 테마 6종, 색상 직접 지정, 디지털/링/아날로그, 글꼴 4종
- 카메라 타임랩스 (세션 길이와 상관없이 약 20초 영상)
- 집중도 분석 (얼굴·시선·눈 감김, 기기 안에서만 처리) + 분 단위 그래프 + 추천 세션 길이
- 최근 기록 (이 브라우저에 저장)
- 강의 모드: 집중 화면 안에서 유튜브 강의나 내 PC 영상 파일을 보면서 타이머 진행

## 실행 방법 (테스트 서버)

카메라 기능은 `localhost` 또는 HTTPS 주소에서만 동작합니다. `index.html`을 더블클릭해서 열면 타이머는 되지만 카메라가 막힐 수 있어요.

이 폴더에서 아래 중 하나를 실행한 뒤 브라우저에서 http://localhost:8765 를 엽니다.

**Python** (설치되어 있다면)
```bash
python -m http.server 8765
```

**Node.js** (설치되어 있다면)
```bash
npx serve -l 8765
```

종료는 터미널에서 `Ctrl + C`.

## 사용 방법

### 1. 목표 시간 정하기
- **목표 시간** 칸에 시간·분·초를 입력하거나 `25분` `50분` `90분` `2시간` 버튼을 누릅니다.
- **표시 방식**: `스탑워치`는 0부터 올라가고, `남은 시간`은 목표 시간에서 내려갑니다.
- 기록이 2회 이상 쌓이면 **최근 기록**에 추천 세션 길이가 나오고, 버튼 한 번으로 그 시간으로 설정할 수 있어요.

### 2. 시계 꾸미기
- 색 버튼(12)으로 테마를 고릅니다. 기본은 검정 바탕에 흰 숫자예요.
- **모양**(디지털 / 링 / 아날로그), **글꼴**, **배경·숫자·강조·보조 색**을 바꿀 수 있어요.
- `초 표시`, `현재 시각/날짜 함께 표시`를 켜고 끌 수 있어요.
- 바꾼 내용은 바로 **미리보기**에 보이고, 다음에 열어도 그대로 저장돼 있어요.

### 3. 강의 함께 보기 (선택)
강의를 들으면서 타이머를 쓰고 싶을 때 켭니다.
1. `집중 화면 안에서 강의 틀기`를 체크해요.
2. 둘 중 하나를 골라요.
   - **유튜브 링크**: 영상 주소를 붙여넣어요. `watch?v=`, `youtu.be`, 재생목록, `&t=90s`(시작 위치) 모두 돼요. "✓ 영상 확인됨"이 뜨면 준비 끝이에요.
   - **내 PC 영상 파일**: 파일을 골라요. 여러 개를 고르면 순서대로 이어서 재생돼요.
   - 영상 길이가 확인되면 "길이 12:34"처럼 표시돼요 (여러 파일이면 합친 길이).
   - **목표 시간을 강의 길이에 자동으로 맞추기**를 켜두면 영상을 고르는 순간 목표 시간이 **영상이 끝나는 시간(초 단위까지)**으로 바로 바뀌어요. 꺼두면 `이 길이로 목표 설정` 버튼으로 한 번만 맞출 수 있어요.
   - 유튜브 링크에 시작 위치(`&t=5m`)가 있으면 그 지점부터 남은 길이로 맞춰요. 재생목록은 전체 길이를 알 수 없어서 첫 영상 길이만 맞추거나 직접 정해야 해요.
   - 일시정지하거나 배속으로 보거나 **유튜브 광고**가 나오면 실제로 영상이 끝나는 시간과 차이가 생겨요. 그럴 땐 아래 옵션을 켜세요.
   - **영상이 끝나면 타이머도 끝내기**를 켜두면 목표 시간이 아니라 **마지막 영상이 실제로 끝나는 순간** 끝나요. 광고·일시정지·배속이 저절로 반영되고, 목표 시간을 넘기면 시계에 `+01:12 연장`처럼 보여요. 결과에는 "강의 완주"로 남아요.
3. 시작하면 왼쪽에 강의, 오른쪽에 타이머가 나와요. 강의 화면을 클릭해서 일시정지·배속·탐색을 해도 **이탈로 기록되지 않아요.**
4. 목표 시간이 끝나면 강의도 자동으로 멈춰요 (`영상이 끝나면 타이머도 끝내기`를 켰다면 영상이 끝날 때 타이머가 끝나요).

알아둘 점
- 유튜브는 **테스트 서버(localhost)나 HTTPS 주소로 열어야** 재생돼요. `index.html`을 더블클릭해서 열면 안 될 수 있어요.
- 인프런·패스트캠퍼스·클래스101 같은 유료 강의 사이트는 다른 사이트 안에 넣는 걸 막아둬서 쓸 수 없어요 (나중에 크롬 확장 프로그램으로 지원 예정).
- 고른 영상 파일은 새로고침하면 다시 골라야 해요. 유튜브 링크는 저장돼요.
- 유튜브 광고는 막을 수 없어요. 브라우저에 유튜브 프리미엄 계정으로 로그인돼 있으면 광고 없이 나와요.
- 강의 화면 안에서의 전체화면은 꺼져 있어요. 집중 화면 잠금을 유지하기 위해서예요.

### 4. 옵션 고르기
| 옵션 | 설명 |
|---|---|
| 완료 시 화면 자동 캡처 | 목표 시간이 끝나면 완료 날짜·시각이 찍힌 이미지가 자동으로 다운로드돼요 |
| 카메라 타임랩스 | 진행하는 동안 일정 간격으로 촬영해서, 끝나면 약 20초 영상으로 만들어요 |
| 집중도 분석 | 카메라로 자리 비움·고개 돌림·고개 숙임·눈 감김을 감지해요. 영상은 외부로 전송되지 않아요 |
| 카메라 미리보기 표시 | 진행 중 오른쪽 아래에 내 얼굴을 작게 보여줘요 (화면 안에 잘 들어와 있는지 확인용) |
| 완료 시 진동 / 알림음 | 알림음은 듣던 음악이 잠깐 작아질 수 있어 기본은 꺼져 있어요 |

카메라 옵션을 처음 켜면 브라우저가 카메라 권한을 물어봐요. **허용**을 눌러주세요.

### 5. 시작 전 체크
- 음악을 들을 거라면 **다른 탭이나 앱에서 미리 틀어두세요.** 집중 중에도 계속 나와요.
- `Win + N` → **방해 금지**를 켜서 Windows 알림을 꺼두세요.
- 휴대폰은 손이 안 닿는 곳에 두세요.

### 6. 집중 시작
- **집중 시작** 버튼을 누르거나 `Enter`를 누르면 전체화면으로 바뀌고 타이머가 시작돼요.
- 집중도 분석을 켰다면 **처음 10초 동안은 화면을 바르게 바라봐 주세요.** 이 자세를 기준으로 시선 이탈을 판단해요.
- 마우스를 2초 동안 움직이지 않으면 커서가 사라져요.

### 7. 진행 중에 할 수 없는 것
- **Esc**: 짧게 누르면 안 빠져나가고, 길게 눌러야 전체화면이 풀려요 (Chrome/Edge).
- **다른 창으로 이동, 알림 클릭**: 막을 수는 없지만 **이탈로 기록**되고 결과에 남아요.
- **전체화면이 풀리면** "다시 집중 모드로" 화면이 떠요. 버튼을 누르면 돌아가요.
- **뒤로가기 / 탭 닫기**: 막혀 있어요. 닫으려고 하면 경고가 떠요.
- **그만두고 싶을 때**: 아래쪽 `3초 길게 눌러 포기` 버튼을 3초 동안 누르고 있으면 끝나요.

### 8. 결과 보기
목표 시간이 끝나면 결과 화면으로 넘어가요.
- **집중도 %**: 카메라 분석 + 화면을 떠나지 않은 비율. 카메라를 안 썼다면 화면 유지율만 보여줘요.
- **완료 캡처**: 자동 저장된 이미지. `이미지 저장`, `공유하기`로 다시 받을 수 있어요.
- **요약**: 진행 시간, 최장 연속 집중, 이탈 횟수·시간, 첫 이탈 시점.
- **분 단위 집중도**: 1분마다 막대로 표시. 빨간색일수록 집중도가 낮았던 구간이에요.
- **언제 집중이 깨졌나**: 집중이 무너지기 시작한 시점과 다음 세션 추천 길이, 이탈 목록.
- **타임랩스**: 영상이 만들어지면 바로 재생되고 `영상 저장`으로 받을 수 있어요. 만드는 데 약 20초 걸려요.
- `다시 설정하기`를 누르면 처음 화면으로 돌아가요.

### 저장되는 파일
- 완료 캡처: `focus_날짜_시각.png` (예: `focus_20261027_143732.png`)
- 타임랩스: `timelapse_날짜_시각.mp4` 또는 `.webm` (브라우저에 따라 다름)
- 모두 브라우저의 **다운로드 폴더**에 저장돼요.

## 자세히

### 1. 첫 버전 — 10/27 🆕
- 목표 시간을 정하면 그 시간만큼 진행 (스탑워치 / 남은 시간 중 선택)
- 집중 모드: 전체화면, Esc를 길게 눌러야 해제 (Chrome/Edge), 뒤로가기·탭 닫기 방지, 화면 꺼짐 방지
- 다른 창·탭으로 가거나 알림을 누르면 이탈로 기록, 전체화면이 풀리면 "다시 집중 모드로" 화면
- 포기는 아래 버튼을 3초 길게 눌러야 가능
- 완료 시 완료 날짜·시각이 찍힌 이미지 자동 저장
- 시계 꾸미기: 테마 6종 (기본 검정 바탕 + 흰 숫자), 색 4가지 직접 지정, 디지털·링·아날로그, 글꼴 4종
- 음악은 마이크를 쓰지 않아 계속 재생됨. 완료 알림음은 음악을 줄일 수 있어 기본 꺼짐

### 2. 카메라 타임랩스 — 10/27 🆕
- 처음 한 번 카메라 권한을 허용하면 이후 시작할 때 자동으로 켜짐
- 세션 길이에 맞춰 촬영 간격을 자동 조절해서 끝나면 약 20초 영상으로 만듦 (mp4 또는 webm)
- 각 장면에 경과 시간과 현재 시각 표시

### 3. 집중도 분석과 결과 리포트 — 10/27 🆕
- 카메라로 자리 비움·고개 돌림·고개 숙임(휴대폰 의심)·눈 감김(졸음 의심) 감지. 영상은 기기 밖으로 안 나감
- 처음 10초 자세를 기준으로 삼아 카메라 위치가 달라도 판단 가능
- 결과: 집중도 %, 1분 단위 그래프, 집중이 무너진 시점, 다음 세션 추천 길이, 졸음 신호, 이탈 목록
- 참고 연구: Mackworth(1948) 지속적 주의 저하, Killingsworth & Gilbert(2010), PERCLOS, Bradbury(2016)

### 4. 완료 캡처에서 완료 시각 띠가 시계와 겹침 — 10/27 🐞
- 링·아날로그 모양일 때 아래쪽 "완료 시각" 띠가 시계 그림을 가림
- 시계를 띠 위쪽 공간에만 그리도록 바꿈

### 5. 1분 세션에서 그래프 축 라벨 중복 — 10/27 🐞
- 아주 짧은 세션에서 그래프 아래에 "1분"이 두 번 나옴 → 같은 라벨은 한 번만 표시

### 6. PC 웹 기준으로 정리 — 10/27 🔧
- 모바일 방해금지 자동 켜기 등은 웹으로 불가능해서 고도화 단계(네이티브 앱)로 미룸
- 모바일로 접속하면 "PC 웹 기준 버전" 안내 표시, 모바일 임시 방법은 접이식 메모로 축소

### 7. 넓은 화면 2단 레이아웃 — 10/27 🔧
- 화면이 넓으면 왼쪽에 미리보기·시작, 오른쪽에 설정. 미리보기는 스크롤해도 고정

### 8. 시작 전 체크 — 10/27 🆕
- 음악 켜두기 / Windows 방해 금지 켜기(Win+N) / 휴대폰 멀리 두기
- 웹은 Windows 알림을 막을 수 없어서 시작 전에 직접 켜도록 안내

### 9. 최근 기록과 추천 세션 길이 — 10/27 🆕
- 세션이 끝날 때마다 이 브라우저에 저장 (최대 50개)
- 최근 10회 평균 집중도와 달성 횟수 표시
- 2회 이상 쌓이면 보통 집중이 떨어지는 시점을 보고 세션 길이 추천, 버튼으로 바로 적용

### 10. 진행 중 커서 숨김, Enter로 시작 — 10/27 🔧
- 마우스를 2초 동안 안 움직이면 커서가 사라짐
- 설정 화면에서 Enter를 누르면 바로 시작

- 폴더 구조와 파일별 역할은 README에 정리

### 14. 강의 모드 — 10/27 🆕
- 집중 화면 안에서 강의를 보면서 타이머 진행: 왼쪽 강의, 오른쪽 타이머 (좁은 화면은 위 강의, 아래 타이머)
- **유튜브 링크**: watch?v= / youtu.be / shorts / live / 재생목록 / 시작 위치(&t=) 링크 모두 인식
- **내 PC 영상 파일**: 여러 개 고르면 이어서 재생, 영상 길이로 목표 시간 맞추기 버튼
- 목표 시간이 끝나면 강의 자동 정지, 결과 화면 제목에 "유튜브 강의 / 영상 N개" 표시
- 강의 안 전체화면은 꺼둠 (집중 화면 잠금 유지)
- 유료 강의 사이트(인프런 등)는 사이트가 막아둬서 불가 → 크롬 확장 프로그램으로 지원 예정
- 새 파일: `js/lecture.js`

### 15. 강의 화면 클릭이 이탈로 잘못 기록될 문제 — 10/27 🐞
- 원래는 창이 포커스를 잃으면(blur) 이탈로 기록했는데, 유튜브 화면(iframe)을 클릭해도 같은 신호가 발생함
- blur 대신 0.2초마다 "이 창이 포커스를 가지고 있는지(hasFocus)"를 확인하는 방식으로 바꿈 → 강의 클릭은 이탈 아님, 다른 창으로 가면 이탈

### 16. 목표 시간을 강의 길이에 자동으로 맞추기 — 10/27 🆕
- 강의 모드에 체크박스 추가 (기본은 꺼짐, 원할 때만 켜기)
- 켜면 영상을 고르는 순간 목표 시간이 영상 길이로 초 단위까지 바뀜
- **내 PC 영상 파일**: 파일 길이를 읽음, 여러 개면 합친 길이
- **유튜브**: 유튜브 플레이어 API로 보이지 않는 플레이어를 잠깐 만들어서 길이를 읽음. 시작 위치(&t=)가 있으면 그만큼 뺌
- 재생목록 전체 길이는 알 수 없음 → 첫 영상 길이만 맞추거나 직접 설정
- 꺼두면 기존처럼 "이 길이로 목표 설정" 버튼으로 한 번만 맞출 수 있음 (분 단위 올림 → 초 단위로 정확하게 변경)
